## 案ごとの処方箋（優先順）

### A案 index.html — 監査で出たクセ03/09の正確な処方箋が見つかった

CASE 27（taste-skill・1,206行の禁止パターン集）の禁止リストが、監査でA案に残った「均等3カラムカード」「中央見出し」を名指しで禁じており、組み替え先まで示している。

1. **中央見出しヒーロー → 左コピー＋右スタッフ実写の非対称スプリット**（CASE 27: 12カラムでコピー1/7・写真7/13）
2. **均等3カラムカード → 大1＋小2の非対称ベント**。大セルにはgallery写真を敷く（CASE 27）
3. **ふわ影 → 2層影**: `0 1px 2px rgba(0,0,0,.04)` ＋ `0 8px 24px rgba(0,0,0,.06)`（CASE 05）。輪郭を締めたまま影だけ柔らかくできる
4. **CTAに押下感**: hoverで浮かせる代わりに `:active { transform: scale(0.97) }`（CASE 05）または「hoverで影が伸び、activeで沈む」（CASE 13）。モバイル主体の応募ボタンに効く
5. **非対称角丸で「こざくら専用DS」化**: 均一角丸をやめ花びら連想の `border-radius: 36px 18px 18px 18px` 系に固定（CASE 15）。眉ラベル（eyebrow）は3セクションに1個までの配給制（CASE 27）

### B案 hitotonari.html — 「紙と手仕事」の質感で明朝路線を深める

CASE 14（紙・活版・手仕事）が直系レシピ。朱`#C73E3A`を深い桜`#B9214C`に置換するだけでほぼ載る。

1. **紙目テクスチャ**: `feTurbulence`のSVGデータURIを `opacity:.045 + mix-blend-mode:multiply` で全面に（CASE 14）
2. **強調の語彙を増やす**: 傍点 `text-emphasis: filled dot`・手描き波線SVG下線・落款風の園ロゴ印（rotate(-7deg)・multiply）（CASE 14）
3. **明朝の懐に余白を合わせる**: 本文行間1.9・ガター72px・`opacity:0.07`の巨大章番号（CASE 06）
4. **級数の振れ幅**: 見出し60px級 × キャプション10.5pxの対比（CASE 23）
5. 監査指摘のglassヘッダー・常時アニメはこの路線と両立しないので除去（CASE 10の「動きは操作した瞬間のみ」規律）

### C案 editorial.html — 数字主役をさらに徹底する材料が豊富

罫線主義・影ゼロの思想はCASE 03/07/12/29と完全に同型。補強部品:

1. **主役数字の極大化**: 給与・年間休日・有給取得率を `clamp(88px,15vw,240px)` 級まで拡大し、kickerとの落差で組む（CASE 12）
2. **見えるグリッド**: 背景に `rgba(0,0,0,.06)` 程度の12カラム縦罫を敷く（CASE 12）
3. **罫線を「彫る」**: 表・数字グリッドをborderでなく `display:grid; gap:1px`＋背景色差で区画化（CASE 30・26）
4. **実スケールのSVG棒/帯グラフ**: 装飾イラストでなく実データ比。配色は桜色の明度3段のみ、IntersectionObserverで見えた瞬間に伸ばす（CASE 20）
5. **数字カウントアップ＋罫線ごとの逐次表示**（CASE 17。GSAPなしでもIO＋CSSで再現可）
6. **募集要項タグに退色パステルchip**（桜色系に置換。CASE 29）、待遇は表＋等幅数字 `tabular-nums`（CASE 02）

### D案 gravure.html — 実装レシピが2本そのまま存在する

1. **CASE 21が「D案の実装レシピそのもの」**: ヒーロー100svhフルブリード＋下向き黒スクリム `linear-gradient(180deg, rgba(20,14,10,.52), rgba(20,14,10,.1) 22%…)`、`background-attachment:fixed`は不使用（iOS対策）、カードは同一aspect-ratio写真＋番号タグ
2. **本命追加: 「先生の一日」sticky写真ストーリー**（CASE 24・26）: 左に `position:sticky` 100svhの写真ステージ、右に時刻ステップ（7:00早番〜19:00降園）。IOの `rootMargin:"-45% 0px -45%"` で中央のステップだけ現在地に。モバイルは負マージンで白カードを写真に重ねる実装例あり。手持ちの daily/flow/scene 写真が使える
3. **ヒーローKen Burns**: 静止画に `scale(1→1.06)/20s` の微ズーム（CASE 7/24）。動画化（ffmpeg zoompan・CASE 22）は任意で、採るならヒーロー1箇所限定＋poster＋reduced-motion対応
4. 写真上の文字可読性は縦オーバーレイグラデ（上18%→下58%の黒rgba）で（CASE 11）

### 4案共通の規律（方法論としての学び）

- **トークンを先に固定して外に出ない**（CASE 02/08/15/27の共通手法）: 「桜色系＋墨＋罫線色＋LINE緑のみ。緑=行動専用、桜=地とアイデンティティ。1色に用途1つ」を明文化して全案に適用する
- **transition: all をやめ、動くプロパティ名指し＋実数値cubic-bezier 2本に固定**（CASE 05/17）
- **動きは「時間が来たら動く」でなく「操作・スクロールに反応する」ものだけ**（CASE 10/16）
- **コピー検閲**: AI常套句と絵文字の明文禁止はコピー面のAI感対策（CASE 29）
- 採用しないと決めたもの: ダーク基調（09/11/17/28/30）、原色ブルータリズム（13）、p5/WebGL/3D常時描画（11/16/19)、マーキー・磁力カーソル（17）、物理エンジン全面採用（18）
